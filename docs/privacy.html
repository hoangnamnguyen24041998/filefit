Privacy Policy

Effective Date: November 19, 2026 • Version 1.0.0

Summary for Users: FileFit does not collect, track, log, or transmit any user data, browsing history, or file contents. All image decoding, conversion, and compression runs 100% locally inside your browser memory. No data ever leaves your device.

1. Information We Do Not Collect

FileFit is built strictly as an offline client-side micro-utility. We deliberately collect zero personal information:

  • No Image Data: Your files, photos, scanned documents, identity cards, and receipts are processed exclusively in your computer's temporary memory (RAM) using the browser's standard Canvas and WebAssembly APIs. They are never uploaded to any remote server or cloud service.
  • No Browsing History: FileFit does not track the URLs or websites you visit.
  • No Analytics or Telemetry: There are zero analytics scripts (no Google Analytics, Mixpanel, Sentry, or third-party pixels).
  • No User Accounts: FileFit requires no account, sign-in, email address, or payment credentials.

2. Data Stored Locally (User Preferences Only)

The only data stored by FileFit is saved locally within your browser using the Chrome Storage API (chrome.storage.sync):

  • Master Power State: Whether FileFit is globally enabled or disabled (boolean).
  • Operating Mode: Whether you selected "Manual Assist" or "Auto-Fit" mode.
  • Target File Size: Your preferred target size threshold (e.g., 500 KB, 1 MB, 2 MB).
  • Auto-Convert to JPG: Your preference for converting HEIC/WebP/PNG to JPG (boolean).
  • Excluded Domains: Hostnames where you have clicked "Pause" to skip interception.

This preference data never leaves Google's encrypted browser sync infrastructure.

3. Chrome Extension Permissions Justification

FileFit requests only the minimal set of permissions required to function:

  • storage: Used strictly to save your size presets, operating mode, and domain pause preferences across browser sessions.
  • activeTab: Used strictly to inspect the hostname of the currently active tab when you open the popup, allowing you to pause or resume interception on that specific domain.
  • <all_urls> (Content Script): Required because file upload fields (<input type="file">) exist across unpredictable third-party websites, e-commerce stores, applicant portals, and government forms. The content script operates passively and activates only when you select a file in an upload field.

4. Zero Remote Code Execution

In accordance with Google Chrome Web Store Manifest V3 security requirements:

  • All scripts, stylesheets, and WebAssembly modules (including the HEIC decoder) are packaged 100% locally within the extension archive.
  • FileFit contains no eval(), no new Function(), and loads no remote scripts from CDNs or external endpoints.

5. Children's Privacy

FileFit does not collect any personal information from anyone, including children under the age of 13.

6. Changes to this Policy

Because FileFit operates 100% locally and collects zero data, this policy is simple and durable. If we make material modifications, updates will be reflected in extension release notes and at this URL.
